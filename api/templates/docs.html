AutoGarage Pro API v2.0

Base URL: https://autogarage-api-wwj4.onrender.com/api

Authentication

POST/auth/register/Register new garage
POST/auth/login/Login, returns JWT token

Customers

GET/customers/List all customers
POST/customers/Create customer
POST/quick-customer/Quick create (name + phone only)

Vehicles

GET/vehicles/List all vehicles
POST/quick-vehicle/Quick create with customer link

Work Orders

GET/work-orders/List work orders
POST/quick-workorder/Quick create by plate
GET/qr/{srn}/Generate QR code

Inventory & Payments

GET/inventory/List inventory
GET/payments/Payment history
GET/invoices/Invoice list

AI & Reports

POST/ai/diagnose/AI fault code diagnosis
GET/ai/codes/Supported fault codes
GET/dashboard/Dashboard statistics
GET/reports/revenue/Revenue report

System

GET/mechanics/Mechanic profiles
GET/appointments/Appointment list
GET/audit-logs/Activity audit trail
GET/notifications/User notifications

All endpoints require Authorization: Bearer {token} header except auth endpoints.
